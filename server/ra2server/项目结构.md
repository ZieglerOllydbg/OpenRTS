# RA2 Server 项目结构

## 项目概览

`ra2server` 是一个基于 Java 11、Gradle、Netty 的 WebSocket 游戏服务器。项目主要负责玩家匹配、房间管理、帧同步、连接会话维护和测试客户端支持。

服务端启动后默认监听 `8080` 端口，WebSocket 地址为：

```text
ws://localhost:8080/ws
```

## 启动入口

### `org.game.ra2.GameStartUp`

位置：

```text
src/main/java/org/game/ra2/GameStartUp.java
```

职责：

- 初始化 `MatchService` 匹配服务。
- 创建并启动 `WebSocketServer`。
- 默认监听 `8080` 端口。

主启动流程：

```text
GameStartUp
└── MatchService.getInstance()
└── new WebSocketServer(8080, matchService)
└── server.start()
```

## 核心模块

## 网络模块 `netty`

目录：

```text
src/main/java/org/game/ra2/netty/
```

文件：

```text
WebSocketServer.java
WebSocketServerInitializer.java
WebSocketFrameHandler.java
```

职责：

- 基于 Netty 启动 WebSocket 服务。
- 注册 HTTP 编解码器、聚合器和 WebSocket 协议处理器。
- 处理 `/ws` 路径上的 WebSocket 消息。
- 按消息类型分发到匹配服务或房间服务。

消息分发规则：

```text
ping       -> 直接返回 pong
match      -> MatchService
cancelMatch -> MatchService
其他消息   -> 根据 channelId 查询 roomId，再转发到 RoomService
```

## 匹配模块 `service.MatchService`

位置：

```text
src/main/java/org/game/ra2/service/MatchService.java
```

职责：

- 维护玩家匹配请求队列。
- 按房间类型维护等待队列。
- 匹配人数满足要求后创建房间。
- 处理玩家主动取消匹配。
- 处理匹配阶段玩家断线。

支持的房间类型：

```text
SOLO  -> 1 人
DUO   -> 2 人
TRIO  -> 3 人
QUAD  -> 4 人
OCTO  -> 8 人
```

匹配线程：

```text
MatchThread
└── 每 50ms 处理一次匹配消息
└── 取消匹配和匹配阶段断线都通过消息队列串行处理
└── 每种 RoomType 独立检查是否满足开房人数
```

## 房间服务模块 `service`

目录：

```text
src/main/java/org/game/ra2/service/
```

主要文件：

```text
RoomServiceManager.java
RoomService.java
WebSocketSessionManager.java
Message.java
```

职责：

- `RoomServiceManager`：管理所有房间服务，负责创建、查找、移除房间。
- `RoomService`：管理单个房间的消息队列、房间创建、玩家准备、帧输入、房间销毁。
- `WebSocketSessionManager`：维护连接和房间映射，负责线程安全地发送 WebSocket 消息。
- `Message`：封装 `channelId` 和 JSON 消息数据。

房间线程分配：

```text
RoomServiceManager
└── 默认创建 4 个 RoomThread
└── 新房间按轮询方式分配到不同 RoomThread
```

## 房间线程模块 `thread`

目录：

```text
src/main/java/org/game/ra2/thread/
```

文件：

```text
RoomThread.java
Room.java
```

职责：

- `RoomThread`：以 20fps 频率驱动房间消息处理和房间更新。
- `Room`：保存玩家、准备状态、帧输入、当前帧号和房间销毁状态。

帧同步流程：

```text
RoomThread
└── RoomService.processMessageQueue()
    ├── ready      -> Room.markPlayerReady()
    ├── frameInput -> Room.addFrameInput()
    └── leave      -> RoomService.handlePlayerLeave()
└── RoomService.pulse()
    └── Room.update()
        └── processFrameSync()
            └── broadcastFrameSync()
```

房间销毁规则：

```text
所有玩家离开或断线
└── 开始 30 秒倒计时
└── 超时后 RoomServiceManager 移除房间服务
```

## 主链路总结

```text
客户端连接 ws://localhost:8080/ws
└── WebSocketFrameHandler 接收消息
    ├── ping 直接返回 pong
    ├── match 投递到 MatchService
    ├── cancelMatch 投递到 MatchService
    └── 房间消息投递到 RoomService

MatchService
└── 按 RoomType 排队匹配
└── 可从等待队列取消匹配
└── 人数满足后创建 RoomService
└── RoomService 创建 Room 并通知 matchSuccess

RoomService
└── 收到 ready 后标记玩家准备
└── 全员 ready 后广播 gameStart
└── 收到 frameInput 后写入 Room

RoomThread
└── 每 50ms 驱动一次房间更新
└── Room 广播 frameSync
```
